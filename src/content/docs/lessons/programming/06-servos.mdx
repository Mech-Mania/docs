Servos are driven for the most part using PWM. The angle (for a standard 180 or 270 degree servo), or the speed (for a continuous servo), depend on the pwm pulse width recieved. 

For example, for an [MG90s](https://www.alldatasheet.com/datasheet-pdf/view/1132104/ETC2/MG90S.html) servo (along with most other hobby servos), a pulse width of 1 milliseconds (ms) corresponds to 0 degrees, and 2ms corresponds to 180 degrees. Most hobby servos will also expect a PWM frequency of 50Hz (20ms).

### Libraries

While we *can* implement servo control manually, it is often much simpler and more efficient to use libraries to control them.

<Tabs syncKey="boards">
<TabItem label="Arduino">

To drive servos on an Arduino, in general we use the [`Servo.h`](https://docs.arduino.cc/libraries/servo/) library (by Michael Margolis, Arduino). 

For more information on specific methods see the library's [documentation](https://docs.1arduino.cc/libraries/servo/#Methods).
```c++
/*
    Servo control for a MG90s Servo
*/
#include <Servo.h>

#define SERVO_PIN 13

Servo srv;

void setup(){
    // Attach the servo to the pin
    srv.attach(
        SERVO_PIN,
        1000, // Set min PWM pulse width to 1ms (1000us) 
        2000  // Set max PWM pulse width to 2ms (2000us)
    );
}

void loop(){
    // Set the servo to 0 degrees
    srv.write(0);
    delay(1000);

    // Set the servo to 180 degrees
    srv.write(180);
    delay(1000);
}
```

</TabItem>
<TabItem label="Esp32">

To drive servos on an ESP32, in general we use the [`ESP32Servo.h`](https://docs.arduino.cc/libraries/esp32servo/) library (by Kevin Harrington,John K. Bennett). 
The library is an ESP32 port of the Arduino [`Servo.h`](https://docs.arduino.cc/libraries/servo/)) library, and as such has the same syntax.

For more information on specific methods see the library's [documentation](https://github.com/madhephaestus/ESP32Servo#library-description).

```c++
/*
    Servo control for a MG90s Servo
*/
#include <ESP32Servo.h>

#define SERVO_PIN 13

Servo srv;

void setup(){
    // Allocate timer for the servos
    ESP32PWM::allocateTimer(0); // 

    // Attach the servo object to the physical pin connected to the servo
    srv.attach(
        SERVO_PIN,
        1000, // Set min PWM pulse width to 1ms (1000us) 
        2000  // Set max PWM pulse width to 2ms (2000us)
    );
}

void loop(){
    // Set the servo to 0 degrees
    srv.write(0);
    delay(1000);

    // Set the servo to 180 degrees
    srv.write(180);
    delay(1000);
}
```

</TabItem>
</Tabs>

We can set the pulse width range by passing the options `min` (default 544us) and `max` (default 2400us) on the `Servo.attach(pin,min,max)`. This wwill set what frequencies the library interprets 0 and 180 degrees.

These values should be available on the datasheet of any given servo, and setting them wrong could lead to improper servo function.
