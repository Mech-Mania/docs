To code the microcontrollers used in Mechmania, namely the [Arduino](https://www.arduino.cc/) and the [Esp32](https://www.espressif.com/en/products/socs/esp32), we recommend that you use the Arduino IDE or the Arduino CLI (the latter of which is more versatile, and can be used with VsCode, but has a more involved setup).

If you are new to programming, we recommend you follow this guide from here to setup the Arduino IDE, otherwise you can skip to [here](http://localhost:4321/lessons/u4-programming/401-setting-up/#arduino-cli-setup) for use of the Arduino CLI
