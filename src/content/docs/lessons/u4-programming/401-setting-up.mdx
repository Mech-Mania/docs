To code the microcontrollers used in Mechmania, namely the [Arduino](https://www.arduino.cc/) and the [Esp32](https://www.espressif.com/en/products/socs/esp32), we recommend that you use the Arduino IDE or the Arduino CLI (the latter of which is more versatile, and can be used with VSCode, but has a more involved setup).

If you are new to programming or are unfamiliar with the use of terminal commands, we recommend you follow this guide from here to setup the Arduino IDE, otherwise you can skip to [here](http://localhost:4321/lessons/u4-programming/401-setting-up/#arduino-cli-setup) for use of the Arduino CLI

#### Arduino IDE Setup

First, download the correct Arduino IDE executable for your operating system from the [official site](https://www.arduino.cc/en/software/)

<Tabs>
    <TabItem label="Linux">
        <Image src={img_arduino_ide_linux} width={600} alt="Download Arduino IDE for Linux" />
        
        You should be able to find the downloaded IDE inside of your `/home/<user>/Downloads/` folder. Rename it to `arduinoIDE.AppImage`.

        Open a terminal instance to the Downloads folder, make the IDE executable, then run it.
        ```bash
        
        # navigate to downloads
        cd /home/<user>/Downloads/
        
        # add execute permission to the AppImage
        chmod +x ./arduinoIDE.AppImage

        # run the program
        ./arduinoIDE.AppImage
        ```
        You should be able to also run it by double clicking on the icon in the file browser or desktop

    </TabItem>
    <TabItem label="Windows">
        <Image src={img_arduino_ide_windows} width={600} alt="Download Arduino IDE for Windows" />
        
        Find the downloaded installer inside yof your `C:\Users\<user>\Downloads\` directory. Open the installer and then follow the install steps. The default install options should be perfect unless you have any special circumstances, such as needing to install on a different disk than `C:/`.

        You should be able to launch the IDE by searching up `Arduino` inside the Start Menu and clicking `Open`.

    </TabItem>
</Tabs>
